Stall Zone < 18%
Did you know? An electric motor is an inductive load (v = L · didt). When the MOSFET turns off in microseconds, the collapsing magnetic field in the motor windings generates a reverse voltage spike that can exceed 100V! The flyback diode (D3) provides a safe return path for this recirculating current, clamping the drain voltage and shielding the MOSFET from destructive avalanche breakdown.
