Channel Inversion Layer: When Vgs exceeds Vth, positive gate charge repels bulk holes and attracts mobile conduction electrons from the N+ source/drain, forming a conductive N-channel sheet under the gate oxide.

1. Saturation Regime (Vds ≥ Vgs - Vth)

Inactive
Id = 12 · k · WL · (Vgs - Vth)2

Occurs when Vds ≥ Vgs - Vth. The channel pinches off at the drain side. Drain current saturates into a constant, voltage-controlled current source independent of Vds.

Id = 1.60 A

2. Triode / Linear Regime (Vds < Vgs - Vth)

Active
Id = k · WL · [(Vgs - Vth) · Vds - Vds22]

Active when Vds < Vgs - Vth. Continuous conductive channel from source to drain. Functions as a precision voltage-controlled resistor ideal for low-loss switching.

Id = 1.48 A

3. Conduction On-Resistance (Ohmic Limit)

Switching Metric
Rds(on) = 1k · (W/L) · (Vgs - Vth)

Governs I2R heat dissipation and conduction loss in switching converter stages. Driving the gate with Vgs = 10V to 12V maximizes channel inversion, dropping Rds(on) to milliohms.

Rds(on) = 18.5 mΩ

Why MOSFET Switches Run Cold

A transistor dissipates thermal power proportional to P = Id × Vds. Look at what happens in our PWM lab:

STATE 1: SWITCH OFF (CUTOFF)
Id = 0 A  •  Vds = 12 V
Power Loss = 0.00 W
STATE 2: SWITCH ON (DEEP TRIODE)
Id = 0.25 A  •  Rds(on) = 17.5 mΩ
Power Loss = 1.1 mW

Because the transistor transitions rapidly between these two states at 1.44 kHz without dwelling in linear saturation, efficiency easily exceeds 96% without requiring a bulky heatsink.

Parabolic Turn-On
Did you know? Unlike bipolar junction transistors (BJTs) which require continuous base current (Ib = Ic / β) to stay on, a MOSFET's gate is an insulated capacitor (SiO2). Once charged, the DC steady-state gate current is literally zero amperes! Energy is only consumed during rapid charging and discharging of the gate capacitance (Qg ≈ 60 nC), making MOSFETs the uncontested king of modern high-frequency power electronics.
